# noisy

Trippy visuals made with Windows GDI Api, fully written on C#! Harmless, visuals-only, safe.

![](497499606-8e426714-a257-4621-9e5a-d4572fab2b2f.png)

Quit the app using `Ctrl + Alt + Q`.
